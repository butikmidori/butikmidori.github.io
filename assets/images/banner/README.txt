BANNER PROMO MI.DO.RI

Website membaca dua file berikut:

DESKTOP
Nama: banner-promo-desktop.webp
Ukuran yang disarankan: 1800 × 520 px
Rasio: sekitar 45:13 atau 3,46:1

PONSEL
Nama: banner-promo-mobile.webp
Ukuran yang disarankan: 1200 × 675 px
Rasio: 16:9, tetap landscape

Lokasi GitHub:
assets/images/banner/

Cara mengganti:
1. Buat desain banner desktop dan ponsel.
2. Simpan keduanya sebagai WebP.
3. Gunakan nama file persis seperti di atas.
4. Masuk ke folder `assets/images/banner/` di GitHub.
5. Replace kedua file tersebut.
6. Klik Commit changes.
7. Tunggu GitHub Pages selesai deploy.
8. Tekan Ctrl + F5.

Selama nama dan lokasinya sama, index.html, style.css, dan app.js
tidak perlu diubah lagi ketika mengganti desain banner.
