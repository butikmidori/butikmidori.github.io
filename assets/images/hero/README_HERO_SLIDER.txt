HERO SLIDER mi.do.ri v3.0.1

Gunakan tiga nama file berikut di folder assets/images/hero/:
1. hero-koleksi.webp
2. hero-koleksi-2.webp
3. hero-koleksi-3.webp

Saran ukuran setiap gambar:
- Rasio mendekati 4:3 atau 3:2
- Minimal 1400 x 1000 piksel
- Format WebP
- Posisi objek utama berada di area tengah gambar

Jika gambar ke-2 atau ke-3 belum tersedia, slider otomatis menyembunyikan gambar yang tidak ditemukan tanpa merusak tampilan hero.
