Nama file yang dibaca website:
hero-koleksi.webp

Lokasi:
assets/images/hero/hero-koleksi.webp

Cara mengganti:
1. Siapkan foto koleksi utama.
2. Disarankan ukuran 1600 × 1280 px (rasio 5:4).
3. Pastikan objek/model berada di tengah agar aman pada layar ponsel.
4. Simpan sebagai WebP dengan nama tepat: hero-koleksi.webp
5. Upload atau Replace file pada folder ini di GitHub.
6. Commit changes, tunggu deployment, lalu tekan Ctrl + F5.

Tidak perlu mengubah index.html, style.css, atau app.js ketika
mengganti foto dengan nama dan lokasi yang sama.
